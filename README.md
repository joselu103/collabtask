# CollabTask

## A Real-Time Collaborative Task Management API

### Introduction

A REST + WebSocket API for a multi-tenant task management platform.

### Authentication & Authorization:

- OAuth2 + JWT
- Password hashing with bcrypt

### Functionalites:

- Organizations with Role-Based Access Control (RBAC).

### Documentation:

- Automatically generated thanks to FastAPI (check `/docs` and `/redoc`)

### Tech stack:

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- Alembic
- pwdlib + bcrypt
- PyJWT
- PostgreSQL
